# КБ «Мята»

Мобильный кликер про котят, которые строят свою космическую отрасль. Ты — генеральный конструктор: чинишь списанный носитель, разгонный блок и кубсат, выводишь аппарат на солнечно-синхронную орбиту и зарабатываешь на снимках.

Игра открывается по своей ссылке (Vercel / любой хостинг). Яндекс.Игры и Telegram можно накинуть позже, когда будет смысл.

## Что уже есть

- Брифинг кота-президента и разведки
- Ангар: тапаешь по «Камышу-2», «Ласточке-Б» и «Лапке-1», инженеры чинят фоном
- Старт и выведение на ССО 535 км
- Земля, орбита КА и три ППИ
- Заявки котят на съёмку по координатам
- Контур: затвор → сырой кадр на борту → сброс на ППИ → дешифровка → продажа
- Модернизация оптики и смены операторов
- Задел под «Рысь», радар «Ирбис» и ядерный буксир «Топаз»

Прогресс пишется в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Открой [http://127.0.0.1:43217](http://127.0.0.1:43217) с телефона в той же сети или через туннель. На телефон лучше добавить на домашний экран — это обычная веб-страница.

```bash
npm run build
npm start
```
