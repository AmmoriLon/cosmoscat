# КБ «Мята»

Мобильный кликер про котят, которые строят свою космическую отрасль. Ты — генеральный конструктор: чинишь списанный носитель, разгонный блок и кубсат, выводишь аппарат на орбиту и зарабатываешь на снимках.

Игра открывается по своей ссылке (Vercel / любой хостинг).

## Что уже есть

- Брифинг кота-президента и разведки
- Ангар: тапаешь по «Камышу-2», «Ласточке-Б» и «Лапке-1», инженеры чинят фоном
- Старт «Камыша-2» без фона, ракета уходит за край экрана
- Земля и весь флот: у каждого КА своя 3D-модель и своя орбита
- Круговые орбиты и эллипс 350×1450 км, который не врезается в планету
- Заявки: сверху только те, что этот КА может принять (не больше двух). Принятые отмечены отдельно
- Контур: затвор → сырой кадр на борту → сброс на ППИ → дешифровка → продажа
- Новые аппараты собираются мини-играми на реакцию. Верный тап подсвечивает кромку зелёным, промах — красным. Чистая сборка удлиняет срок, кривая — укорачивает
- Телеметрия по тапу на КА: высота, температура, шина, отказы
- Случайные аварии живого аппарата режут срок, коротко всплывают (свайп или 4 секунды) и оставляют красный значок сверху. Списанный аппарат уходит в архив без новых плашек
- Модернизация оптики и смены операторов
- Задел под «Рысь», радар «Ирбис» и ядерный буксир «Топаз»

Прогресс пишется в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Открой [http://127.0.0.1:43217](http://127.0.0.1:43217) с телефона в той же сети или через туннель.

```bash
npm run build
npm start
```
